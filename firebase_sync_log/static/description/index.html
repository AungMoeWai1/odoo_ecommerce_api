Firebase Notification For Ecommerce order

This module sends Firebase Cloud Messaging notifications from Odoo ecommerce workflows to registered mobile devices.

Email Us

KEY HIGHLIGHTS

Order and Invoice Alerts

Customers receive clear notifications when ecommerce orders are confirmed or their delivery status changes.

User Message Notifications

Notifications are sent to the Odoo user connected to the customer partner record.

Notification Log Sync

Notifications are triggered from Odoo order and invoice actions and logged for later review.

Secure Device Registration

Mobile device token are securely stored and send messages to authorized user devices.

Message View Support

The notification helper can be called from any installed Odoo addon that depends on this module.

Firebase Push Notifications

Instant push notifications are delivered through Firebase Cloud Messaging when a valid device token is available.

Configuration and Usage

1. Configure Firebase

Generate a Firebase Admin SDK private key from Firebase Console > Project settings > Service accounts. Rename the downloaded file to hr_intellect.json and place it in: 

firebase_sync_log/key/hr_intellect.json

Keep this service-account file private. Do not commit it to Git or expose it through a web server.

2. Install the dependency

pip install firebase-admin

3. Register the device token

Store the mobile FCM token on the recipient Odoo user using mobile_device_token. Multiple tokens can be stored in mobile_device_tokens when each related record has a token field.

4. Send a notification from another addon

Import the helper and call it from an Odoo model method after the relevant business action: 

from odoo.addons.firebase_sync_log.models import message_notifications

                        message_notifications.send_message_notification(
                            self.partner_id.user_ids[:1],
                            self,
                            "Sale order has been confirmed",
                            f"Your order {self.name} has been confirmed!",
                        )

The helper returns True when at least one notification is sent successfully. It returns False when the user has no device token or Firebase cannot send the message.
